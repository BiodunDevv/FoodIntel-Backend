Architecture

Frontend: Next.js + TypeScript + Tailwind + shadcn/ui

Backend: FastAPI + Motor + JWT + Pydantic

Model: PyTorch transfer learning with MobileNetV3 or EfficientNet

Data: MongoDB for users, foods, and meal logs

Storage: Local uploads by default, Cloudinary optional

Docs: Swagger UI, ReDoc, OpenAPI JSON, markdown docs

Deployment: Local, Docker, Render, Railway, Fly.io

Scope: User-side functionality only for this version

Supported endpoints

  • `POST /api/v1/auth/register`
  • `POST /api/v1/auth/login`
  • `GET /api/v1/auth/me`
  • `PATCH /api/v1/users/me`
  • `GET /api/v1/foods`
  • `GET /api/v1/foods/{slug}`
  • `POST /api/v1/foods/seed`
  • `POST /api/v1/predictions/image`
  • `GET /api/v1/meals`
  • `GET /api/v1/reports/weekly`

Model and dataset notes

The training pipeline supports both custom ImageFolder datasets for Nigerian foods and a Food-101 baseline path through torchvision.

Actual model quality depends on the dataset. Reported nutrition values are placeholders for academic MVP use and should be verified before real deployment.

Run locally

  1. Create `.env` from `.env.example`.
  2. Install `backend/requirements.txt`.
  3. Start MongoDB or `docker compose up`.
  4. Run `uvicorn backend.app.main:app --reload`.
  5. Open `/docs` and seed foods in development.

Ethical note

Nutritional outputs and health scores are estimates for educational use. They are not medical advice and should not be used to diagnose disease or nutrient deficiency.
